# Mapa de Férias

Mapa de férias online para empresas em Portugal: feriados nacionais, regionais e municipais dos 308 concelhos, dias úteis contados automaticamente, regra dos 10 dias úteis seguidos e mapa pronto a imprimir e afixar.

Os dados ficam no browser de quem usa; nada é enviado para servidores.

https://pedrovaz02.github.io/mapa-ferias/
